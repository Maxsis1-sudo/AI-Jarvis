# HOPI Meeting Listener

Native iPhone app (SwiftUI) for recording a meeting, live Czech transcription, creating a structured meeting note and sending it by email.

## MVP flow

1. Enter customer / meeting name and recipient email.
2. Start listening.
3. The app transcribes speech using Apple's Speech framework.
4. Stop the meeting and generate a structured note.
5. Open a prefilled email with the generated note.

> Before recording, make sure participants are informed and that recording complies with your company policy and applicable rules.
